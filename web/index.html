ESP32 Klipper Screen

A portable touchscreen for several Klipper printers, running on a Waveshare ESP32-P4-WIFI6-Touch-LCD-5 or -7, -8 or -10.1.

Install

Which screen do you have?

Pick a size to show the Install button.

Your browser can't flash devices. Use Chrome or Edge on a desktop. Open this page over HTTPS to install.

Steps

  1. Connect the board's USB-UART port to this computer with a data cable.
  2. Pick your screen size above. Each size has its own firmware; the wrong one leaves the screen dark (install the right one to fix it).
  3. Click Install and pick the board's serial port.
  4. On a first install, tick Erase device. When updating, leave it unticked to keep your Wi-Fi and printers.
  5. When it finishes, press reset on the board. On a first boot it opens on Wi-Fi setup.

This replaces the firmware on the ESP32-P4, including Waveshare's demo. The onboard ESP32-C6 Wi-Fi chip isn't touched.
